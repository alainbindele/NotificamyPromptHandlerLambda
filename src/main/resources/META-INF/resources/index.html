🔔 Notificamy Lambda Processor

📋 Service Information

Function: AWS Lambda function for processing Notificamy notifications

Trigger: SQS messages containing query requests

Processing: ChatGPT integration + Email delivery via AWS SES

🔧 Configuration Required

  • OPENAI_API_KEY - Your OpenAI API key
  • AWS_REGION - AWS region (default: us-east-1)
  • AWS_SQS_QUEUE_URL - SQS queue URL
  • AWS_SES_FROM_EMAIL - Verified SES sender email
  • DB_HOST - MySQL database host
  • DB_USERNAME - Database username
  • DB_PASSWORD - Database password
  • DB_NAME - Database name

📨 Expected SQS Message Format

{
  "query_id": 123,
  "prompt": "Remind me about my meeting tomorrow"
}
